# 余生 · AFTERGLOW

面向正在吸烟的成年人的公益互动作品。产品被设计成一场浮夸奢华的「年度烟草贡献者表彰大会」：先用热情过度的企业话术颁发个性化奖项，再让未被财务报表记录的心脏登场，最后由用户亲手拒绝终身贡献奖。

## 体验流程

1. 接受大会贵宾邀请。
2. 填写烟龄、平均日支数和月花费，昵称选填。
3. 依次领取长期合作伙伴奖、稳定增长贡献奖和个人投入成就奖。
4. 阅读个人消费估算和 2025 年烟草行业数据构成的「集团年度报告」。
5. 进入可旋转、缩放的 3D 心脏实验室，观察艺术化的烟草暴露机制表达。
6. 返回大会，亲手熄灭香烟奖杯并拒绝领奖。
7. 生成竖版「拒领奖声明」海报，通过系统分享或保存为 PNG。

分享海报默认不包含烟龄、支数或消费金额。个人输入只保存在当前浏览器的 `localStorage` 中，不上传服务器，也不写入分享链接。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5173/ 。`npm run dev:mobile` 会监听局域网的 5174 端口，`/mobile.html` 提供 360 / 390 / 430 像素手机外框预览。

```sh
npm run build
npm run preview
```

构建结果位于 `dist/`，可以部署到普通静态站点。

## 实现结构

- `product/app.js`：大会叙事、个性化奖项、声音、拒领奖与分享海报。
- `product/style.css`、`product/mobile.css`：桌面和移动端舞台视觉。
- `product/model.js`：纯计算模型、数据来源和口径。
- `games/script.js`：Three.js 程序生成心脏、血流、烟雾与恢复演示。
- `public/share-card.svg`：链接分享封面。

声音由 Web Audio 在用户主动开启后合成，没有外部音频文件。移动端优先调用 Web Share 分享海报；不支持文件分享时退化为系统链接分享或保存 PNG。

## 数据与表达边界

个人累计支数按「日支数 × 365.25 × 烟龄」估算，个人累计花费按「月花费 × 12 × 烟龄」估算。历史消费频率和价格可能变化，所以这些数字只用于理解规模。

行业工商税利与个人消费只在叙事中并置，不推算个人实际纳税额。作品不根据烟龄预测疾病、健康评分、真实器官颜色或寿命。3D 心脏的组织变化、裂隙、斑块和恢复过程均为机制示意和艺术表达，不用于诊断。

页面内「数据说明」列出 WHO、中国疾控周报、新华社引国家烟草局等来源、年份和定义。当前数据快照包括：2025 年行业工商税利 16,570 亿元；2024 调查的现在吸烟者平均每日 15.8 支；WHO 2026 更新的全球烟草死亡估计。

## 验证

```sh
node --test product/model.test.js
npm run build
```

心脏交互仍可通过 `scripts/verify-browser.cjs` 做浏览器回归。大会主流程需要覆盖参评校验、三轮奖项、年度报告、心脏往返、拒领奖、海报下载和 320–430 像素移动端无横向溢出。
